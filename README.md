# Tom&Grace — Social World Edition 1.3

This repository contains the Tom&Grace multiplayer 3D social-world project. The deployment bootstrap in this repository unpacks the complete application bundle before installing server dependencies. See `DEPLOYMENT.md` for setup notes.

Features include a shared 3D penthouse and city, multiplayer movement, room chat, proximity voice signaling, vehicles, wardrobe customization, elevator, sleeping and dancing states, synchronized YouTube TV, and a Spotify embed/link workflow.
